# Changelog

All notable changes to Cat Home Tasker Bot are documented in this file.

The project uses [Semantic Versioning](https://semver.org/).

## [1.0.6] - 2026-09-14

### Fixed

- Prevented bot commands from being processed as passwords, experience values, or changelog text.

## [1.0.5] - 2026-09-14

### Changed

- Improved stability and user experience.
- Split the source code into logical modules for easier maintenance and development.

## [1.0.4] - 2026-09-11

### Added

- Added Russian and English interface support.
- Prepared the localization system for adding more languages.

### Changed

- Improved stability and user experience.

## [1.0.3]

### Changed

- Prepared the first draft release with the application source code contained in a single file.

## [1.0.2] - 2026-01-26

### Added

- Added the ability to complete standard and custom tasks immediately after selecting or creating them.
- Added pagination to the completed-task history with five entries per page.
- Added an in-app bot changelog.
- Added changelog management to the administration panel.

### Changed

- Updated the names of the main menu items.
- Increased the completed-task history limit to the latest 50 entries.
- Added automatic deletion of older history entries.

## [1.0.1]

### Changed

- Reorganized and documented the source code.
- Improved the user interface and interaction flow.

## [1.0.0]

### Added

- Household creation during initial setup.
- Household invitation codes for adding new members.
- A shared list of active household tasks.
- Standard tasks from the built-in task library.
- Custom task creation and editing.
- Completed-task history containing the latest 15 entries.
- User profiles with editable names and genders.
- Household information with summaries of members and their profiles.
- Administration panel for viewing and deleting households, removing users, changing user experience points, and clearing household history.
