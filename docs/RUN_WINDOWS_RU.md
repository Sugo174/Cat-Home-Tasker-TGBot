# Запуск Cat Home Tasker в Windows

[English version](RUN_WINDOWS.md) · [Описание проекта](../README.ru.md)

## Перед началом

Нужны:

- установленный Python 3.14;
- исходники проекта;
- токен Telegram-бота от BotFather;
- адрес SOCKS5-прокси;
- пароль административной панели.

Все команды выполняются в PowerShell из корня проекта.

При обновлении существующей установки сначала сохраните
резервные копии `household.db` и `.env`.

## Первая установка

Создайте окружение и установите зависимости:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Создайте `.env` по образцу `.env.example` и заполните:

```dotenv
BOT_TOKEN=your_bot_token
ADMIN_PASSWORD=your_admin_password
PROXY_URL=socks5://username:password@host:port
```

Все три параметра обязательны.
Не используйте значения примера как рабочие настройки.

Не публикуйте `.env`: в нём находятся токен,
пароль администратора и параметры доступа к прокси.

## Запуск

```powershell
.\.venv\Scripts\python.exe bot.py
```

Бот инициализирует базу данных и начинает получать
обновления Telegram.

Оставьте терминал открытым.
Для остановки нажмите Ctrl+C.

Не запускайте несколько экземпляров с одним токеном.

## Проверка работы

1. Откройте своего бота в Telegram.
2. Отправьте `/start` и выберите язык.
3. Создайте домохозяйство или присоединитесь по приглашению.
4. Проверьте создание задачи, её выполнение и профиль.

Команда `/admin` открывает вход в административную панель.
Используйте пароль из `ADMIN_PASSWORD`.

## Пакетный файл и ярлык

`start_bot.bat` запускает `py -3.14 bot.py`.
Он использует установленный Python 3.14,
а не окружение `.venv`.

Если зависимости установлены только в `.venv`,
используйте прямую команду запуска из раздела выше.

`setup_windows.bat` создаёт ярлык Cat Home Tasker
на рабочем столе. Ярлык запускает `start_bot.bat`.

Создание ярлыка не устанавливает Python и зависимости.

## Обновление и сохранение данных

1. Остановите бота сочетанием Ctrl+C.
2. Скопируйте `household.db` и `.env` в резервную папку
   с ограниченным доступом.
3. Обновите файлы программы, сохранив рабочую базу и настройки.
4. Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

5. Запустите бота.
6. Проверьте существующее домохозяйство, задачи,
   профиль и историю выполнения.

Рабочая база `household.db` находится рядом с `config.py`.
Для резервного копирования простым копированием файла
бот должен быть остановлен.

Не заменяйте рабочую базу пустой базой из другой установки.
Не заменяйте `.env` файлом `.env.example`.

## Решение проблем

### Ошибка No module named aiogram

Зависимости не установлены в Python, которым запущен бот.

Из корня проекта выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

Если ошибка возникает только при запуске ярлыком,
проверьте зависимости установленного Python 3.14:
пакетный файл использует `py -3.14`, а не `.venv`.

### Не удаётся установить зависимости

Проверьте версию Python выбранного окружения:

```powershell
.\.venv\Scripts\python.exe --version
```

Для описанного здесь сценария используется Python 3.14.
Не используйте окружение Python 3.8 от другого проекта.

### Ошибка обязательной переменной окружения

Проверьте наличие `.env` рядом с `config.py`
и заполнение всех трёх параметров:

- `BOT_TOKEN`;
- `ADMIN_PASSWORD`;
- `PROXY_URL`.

Убедитесь, что файл не называется `.env.txt`.

### Бот не отвечает в Telegram

- Проверьте, что процесс бота работает.
- Посмотрите ошибки в терминале.
- Проверьте токен и доступность прокси.
- Убедитесь, что другой экземпляр бота с тем же токеном не запущен.
- Отправьте `/start` повторно.

Не публикуйте токен и пароль прокси при обращении за помощью.

### После обновления не видны прежние данные

Остановите бота и проверьте расположение рабочей базы.
Не удаляйте базы и не копируйте файлы поверх них,
пока не выясните, какая копия содержит нужные данные.
